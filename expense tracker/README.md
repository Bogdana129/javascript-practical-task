# 💜 Expense Tracker

**Expense Tracker** — вебзастосунок для обліку особистих витрат, створений за допомогою HTML, CSS та JavaScript.

## Реалізовані можливості

- Додавання витрат із назвою, сумою та категорією.
- Редагування та видалення витрат.
- Автоматичний підрахунок загальної суми.
- Статистика витрат за категоріями: Їжа, Транспорт, Покупки, Інше.
- Пошук витрат за назвою в реальному часі.
- Фільтрація за категоріями.
- Сортування витрат за датою, назвою та сумою.
- Перевірка правильності введених даних.
- Очищення всіх витрат із підтвердженням.
- Збереження даних у LocalStorage.
- Адаптивний дизайн для комп'ютерів і смартфонів.

## Використані технології

- HTML5 — структура вебсторінки.
- CSS3 — оформлення та анімації.
- JavaScript — інтерактивність і логіка застосунку.
- LocalStorage — збереження витрат у браузері.

## Як запустити

1. Завантажити файли проєкту.
2. Відкрити `index.html` у браузері.
3. Додавати витрати та користуватися функціями застосунку.

Проєкт працює без сервера та бази даних.
