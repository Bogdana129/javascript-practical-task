
# JoinSpace — Форма реєстрації

## Опис проєкту
Інтерактивна форма реєстрації користувача,
створена за допомогою HTML, CSS та JavaScript.

## Функціонал
- Введення імені користувача та Email.
- Створення і підтвердження пароля.
- Перевірка правильності введених даних.
- Перевірка збігу паролів.
- Індикатор надійності пароля.
- Показ та приховування пароля.
- Індикатор заповнення форми.
- Підтвердження згоди з умовами.
- Повідомлення про помилки.
- Очищення форми.
- Повідомлення про успішну реєстрацію.

## Технології
- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Запуск
Відкрийте файл index.html у браузері.

## Особливості
Форма працює без перезавантаження сторінки.
Це навчальний проєкт: справжній акаунт
не створюється, паролі не зберігаються.
